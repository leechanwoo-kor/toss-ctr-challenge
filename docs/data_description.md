# 데이터 명세

## 데이터셋 개요

이 데이터셋은 광고 클릭 예측을 위한 CTR(Click-Through Rate) 모델링 데이터입니다.

## 파일 구성

### train.parquet
- **샘플 수**: 10,704,179개
- **컬럼 수**: 119개 (타겟 변수 `clicked` 포함)

#### 주요 컬럼 설명
| 컬럼명 | 설명 |
|--------|------|
| `gender` | 성별 |
| `age_group` | 연령 그룹 |
| `inventory_id` | 지면 ID |
| `day_of_week` | 주번호 |
| `hour` | 시간 |
| `seq` | 유저 서버 로그 시퀀스 |
| `l_feat_*` | 속성 정보 피처 (l_feat_14는 Ads set) |
| `feat_e_*` | 정보영역 e 피처 |
| `feat_d_*` | 정보영역 d 피처 |
| `feat_c_*` | 정보영역 c 피처 |
| `feat_b_*` | 정보영역 b 피처 |
| `feat_a_*` | 정보영역 a 피처 |
| `history_a_*` | 과거 인기도 피처 |
| `clicked` | **타겟 변수**: 클릭 여부 (0 또는 1) |

### test.parquet
- **샘플 수**: 1,527,298개
- **컬럼 수**: 118개 (식별자 `ID` 포함)

#### 주요 컬럼 설명
| 컬럼명 | 설명 |
|--------|------|
| `ID` | 샘플 식별자 |
| 기타 컬럼 | train.parquet와 동일 (타겟 변수 `clicked` 제외) |

### sample_submission.csv
제출 파일 양식

| 컬럼명 | 설명 |
|--------|------|
| `ID` | 샘플 식별자 |
| `clicked` | 광고를 클릭할 확률 (0.0 ~ 1.0) |
