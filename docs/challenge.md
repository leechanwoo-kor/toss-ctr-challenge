# 토스 NEXT ML CHALLENGE : 광고 클릭 예측(CTR) 모델 개발

토스가 주최하고 데이콘이 주관하는 머신러닝 경진대회로, 실제 토스 앱의 광고 데이터를 기반으로 사용자의 광고 클릭 확률(CTR)을 예측하는 모델을 개발하는 것이 목표입니다.

## 🎯 대회 개요

**주제:** 광고 클릭 예측(CTR) 모델 개발

**배경:** 토스 앱 내 실제 외부 광고 노출/클릭 로그를 기반으로, 주어진 피처를 활용하여 사용자의 클릭 확률을 예측

**특징:**
- 보안 정책상 피처의 상세 의미는 의도적으로 비공개(익명화)
- 최종 모델은 실시간 서빙이 가능한 형태를 가정

**참가 자격:** 25년 12월 중순부터 풀타임 근무가 가능한 누구나 (토스 및 계열사 임직원 제외)

## 🗓️ 주요 일정

- **예선 기간:** 2025.09.08 (월) ~ 2025.10.13 (월) 09:59
- **팀 병합 마감:** 2025.10.06 (월) 23:59
- **본선 산출물 제출:** 2025.10.13 (월) ~ 2025.10.17 (금) 10:00
- **최종 수상자 발표:** 2025.11.03 (월) 10:00

## 💯 평가 방식

### 1. 예선 (리더보드 평가)
Private 리더보드 점수 기준 상위 30팀 본선 진출

**평가 산식:**
- AP (Average Precision): 50%
- WLL (Weighted LogLoss): 50%

**리더보드:**
- Public: 테스트 데이터의 30%로 채점 (대회 기간 중 확인 가능)
- Private: 나머지 70%로 채점 (대회 종료 후 최종 예선 순위 산정 기준)

### 2. 본선 (서면 평가)
제출된 코드와 모델 개발 보고서를 종합적으로 평가

**평가 항목:**
- 모델 성능 (65%): Private 리더보드 점수를 기반으로 환산
- 모델 개발 보고서 (35%)

## 📜 주요 규칙

- **팀:** 개인 또는 최대 4인으로 구성 가능
- **데이터:** 제공된 데이터 외 외부 데이터 사용 금지
- **사전 학습 모델:** 2025.09.08 이전에 공개된 상업적 이용 가능 라이선스 모델만 허용
- **API 모델:** OpenAI, Gemini 등 원격 API 형태의 모델 사용 불가

**코드 제출:**
- 본선 진출 시, 학습(train)과 추론(inference) 코드를 반드시 분리하여 제출
- 모든 라이브러리 버전(requirements.txt) 및 환경 설정 정보 포함 필수

## 💾 데이터셋 정보

**train.parquet:** 학습용 데이터 (약 1,070만 건)
- `clicked` (0 또는 1) 컬럼을 타겟 변수로 사용

**test.parquet:** 평가용 데이터 (약 152만 건)

**주요 컬럼:**
- `gender`, `age_group`, `inventory_id`, `day_of_week`, `hour`, `seq` 등
- `l_feat_*`, `feat_a_*`, `history_a_*` 등 다수의 익명화된 피처 포함
